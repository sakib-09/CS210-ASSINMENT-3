# CS 210 Assignment 3 — Dashboard & Auth UI

A multi-page front-end assignment with login, sign-up, dashboard, history, and profile pages, plus client-side form validation.

## Pages
- `login.html` / `sign-up.html` — auth forms
- `dashboard.html` — main dashboard view
- `history.html`, `profle.html` — supporting pages

## Tech stack
- HTML, CSS (`style.css`)
- JavaScript form validation (`validation.js`)

## What I learned
- Structuring a multi-page static site with shared styling
- Client-side validation for login/sign-up forms
- Keeping navigation consistent across pages

## How to view
Open any `.html` file in a browser. Start with `login.html`.
